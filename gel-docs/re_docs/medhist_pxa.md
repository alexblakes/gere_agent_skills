# Accessing and comparing medical history data with Participant Explorer

[Give us feedback on this tutorial](https://www.smartsurvey.co.uk/s/00ZW4I/)

## Searching

Participant Explorer is an ontology-aware no code tool for searching for participants. You can use it to search for phenotypes using natural language and combine terms in quite complex queries.

In this tutorial, we assume that you have [searched by participant id(s)](../pxa_search/).

## Medical history data for a single participant

From a [participant page](../pxa_participant/), you can view the medical history in a table or a graph.

## Compare medical history of multiple participants

If you search by multiple participants, you can [compare their medical histories](../pxa_compare/).
