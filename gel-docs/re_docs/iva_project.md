# IVA project and studies

Studies are datasets that you can access in IVA. You will be able to see a breakdown of these studies by clicking on the username tab on the top menu and selecting Projects.

## Studies in IVA v3.2.2

The data corresponds to 100kGP release v16, minus withdrawn participants up to release v19.
