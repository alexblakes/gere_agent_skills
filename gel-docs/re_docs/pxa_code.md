# Participant Explorer code systems

You can explore the code systems used in Participant Explorer by clicking on Code Systems at the top right of Participant Explorer.

Here you can click on any code system to open the official external browser for this code system (if available) in a new tab.

If there is no external browser available, this will instead open the built in code-system browser. This allows you to see the codes available, their definitions and the ontology structure.
