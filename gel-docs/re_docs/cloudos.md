# CloudOS

CloudOS is an alternative method for accessing some [Genomics England data](../cloudos_data/). Accessing CloudOS requires separate registration. You can get to CloudOS in a separate research environment, known as Cloud-RE, or in the main RE.

CloudOS is a platform provided by LifeBit and provides a number of tools for working with the data.

## CloudOS access

If you have registered for CloudOS access, you can use in two ways:

- From within the main RE. Click on the icon from the desktop.
- From the CloudRE. This is a separate Amazon Workspace. If you have registered, you will have been sent the registration code. We will be decommissioning this in future, and will provide you with sufficient notice before this happens.

> **CloudOS registration:**
>
> CloudOS requires separate registration, please [contact us](https://www.genomicsengland.co.uk/service-desk) to request access.

## The CloudOS platform

[CloudOS](https://lifebit.atlassian.net/wiki/spaces/CD/overview) is an application provided by [LifeBit](https://www.lifebit.ai/), which allows you to access and analyse [GEL data](../data_overview/) on the Cloud.

CloudOS allows you to:

- [Filter participants with cohort browser](https://lifebit.atlassian.net/wiki/spaces/CD/pages/813106752/Build+a+cohort)
- [Run batch jobs and pipelines on the Cloud](https://lifebit.atlassian.net/wiki/spaces/CD/pages/813040367/Advanced+Analytics)
  - Access shared pipelines from LifeBit and GEL, including:
    - [GWAS pipeline](../gwas/)
  - [Bring in your own pipelines](https://lifebit.atlassian.net/wiki/spaces/CD/pages/813040685/Add+a+new+pipeline)
- [Write code and interact with the data using Jupyter notebooks](https://lifebit.atlassian.net/wiki/spaces/CD/pages/813105195/Run+interactive+analysis)

Documentation on the CloudOS application is provided by LifeBit. You will need to request access to the CloudOS documentation via [Service Desk](https://www.genomicsengland.co.uk/service-desk).

[CloudOS documentation](https://lifebit.atlassian.net/wiki/spaces/CD/overview)

## Data available in CloudOS

You can access the 100kGP and COVID-19 data in CloudOS.

[CloudOS data documentation](../cloudos_data/)

## Sharing data and results between CloudOS and the RE

If you are working with CloudOS, you can transfer files between CloudOS and the workspace.

- To transfer files from CloudOS to the workspace, just download from CloudOS. Files will automatically be put into your Downloads folder.
- To transfer files from the workspace into CloudOS, use Import data in the CloudOS file explorer. You can import from any [desktop folders or from HPC folders that are mounted on the desktop](../home_directory/).

## Export from Cloud-RE

The other application available in the Cloud-RE is [Airlock](../airlock/), which you can use to export the results of your analyses in the same way as you would from the RE.
