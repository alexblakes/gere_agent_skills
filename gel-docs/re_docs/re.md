# Technical information

The Genomics England Research Environment consists of two main platforms, an Ubuntu Virtual Desktop Interface (VDI) hosted by AWS and a High Performance Compute (HPC) cluster.

## Research Environment Desktop

### Access

[This document](../access/) details how to install an AWS client, set up two-factor authentication and access the RE with AWS.

### Use of the Research Environment desktop

The Research Environment desktop is best suited for light computational tasks, such as generating summaries from phenotypic data, doing simple LabKey queries and so on. Memory and processing power is limited.

## HPC environment

All heavy compute tasks **must** be run on the [Genomics England High Performance Compute (HPC)](../hpc/) cluster. To run such jobs you will need to connect to the login node and submit the job from there.
