# Terminal application

The Research Environment runs on [Linux](https://en.wikipedia.org/wiki/Linux). You can access the Terminal by clicking on the application on the Research Environment Desktop. From here you can access the [file system](../home_directory/) and the [HPC](../hpc/).

We do not allow you to use directory traversing to find genome files for participants, as you may find genomes of participants who have since withdrawn consent and any requests to export these data via [Airlock](../airlock/) will be rejected. The best way to find the locations of genome files is using the latest [LabKey](../general_clinical/) `genome_file_types_and_paths` table or file locations on the latest version [Participant Explorer](../pxa/), as we know that these files are currently consented for use.

## Resources for learning Bash

There are a variety of online resources for learning Bash and Bash scripting:

- The [Linux Journey](https://linuxjourney.com/) provides resources for learning about linux in general, which includes a section on [working in the Shell](https://linuxjourney.com/lesson/the-shell) and other sections on [working with text](https://linuxjourney.com/lesson/stdout-standard-out-redirect) (including stdin and stdout) and [text editors and regular expressions](https://linuxjourney.com/lesson/regular-expressions-regex).
- [Ryans Tutorials](https://ryanstutorials.net/linuxtutorial/) has a comprehensive tutorial that covers all aspects of Bash and a short introduction to Linux and Bash scripting. It also has a [command-line cheatsheet](http://ryanstutorials.net/linuxtutorial/cheatsheet.php) and [Vim cheatsheet](http://ryanstutorials.net/linuxtutorial/cheatsheetvi.php) that might prove useful.
- For more in-depth Bash scripting, Ryans Tutorials also has a [Bash scripting tutorial](http://ryanstutorials.net/bash-scripting-tutorial/).
- IBM developerWorks has a 'Learn Bash By Example' section among some other in-depth Linux tutorials, it is split into three parts: [Part 1](https://www.ibm.com/developerworks/linux/library/l-bash/index.html) | [Part 2](https://www.ibm.com/developerworks/linux/library/l-bash2/index.html) | [Part 3](https://www.ibm.com/developerworks/library/l-bash3/index.html).
