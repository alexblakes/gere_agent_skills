# Rocket chat - communicate with other RE users

> **Rocket chat end of life:**
>
> We discontinued the Rocket Chat application in the Genomics England Research Environment on Friday, 21st June 2024.
>
> We apologise for any inconvenience it may cause. If you use Rocket Chat for your work, please [raise a service desk ticket](https://jiraservicedesk.extge.co.uk/plugins/servlet/desk) with the description "Rocket Chat EoL" with details of your needs.
>
> While we may not be able to address these needs immediately, this will help us investigate alternative platforms with similar functionality.

June 24, 2024
